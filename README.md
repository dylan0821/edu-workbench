# 教培工作台

**[在线演示](https://dylandong.top/edu-workbench/)** 可以免登录切换管理员、教师和学生视角。管理员可以查看师生档案、启停样例账号、试排课和调课，师生可以体验课表、课程大纲、作业和课程群。演示使用虚构数据，操作仅在当前页面生效，刷新即重置。实时课堂、录播播放和 AI 助手需自行部署完整版。

面向小班教培场景的轻量级教学、教务与 AI 协同工作台（v0.2.0）。基于 **Node.js (>= 24)** 原生 HTTP / SSE 与内置 `node:sqlite`（WAL 模式）构建，核心服务仅引入 `@deepseek-ai/dsh` 用于内置智能教务助手，单机即可开箱运行，支持桌面端、iPad 与手机端自适应访问。

## 核心功能

### 1. 角色与权限隔离
支持 **管理员**、**教师**、**学生** 三类角色，所有接口与静态/媒体资源均在服务端按身份、授课归属、班级在读状态及试听有效期严格鉴权：
- **管理员**：全站教务、账号管理、排课、班级、学生档案、DeepSeek 智能助手与系统设置。
- **教师**：仅访问自己授课的班级/课程、课次、作业、资料、录播、课程大纲与课程群。
- **学生**：支持用户名或手机号登录、自助修改资料与密码、账号有效期控制；支持**多孩共用家长手机号独立开号**；仅可见本人在读班级及有效限时试听的内容。
- **安全机制**：登录防爆破限流、HttpOnly Session Cookie（HTTPS 自动附加 `Secure`）、安全响应头（`nosniff` / `DENY` / `same-origin`）及防路径穿越校验。

### 2. DeepSeek 智能教务助手（AI Copilot）
- **内置 DeepSeek Harness + MCP**：集成 `@deepseek-ai/dsh` 运行时与本地 `workbench` MCP 服务，管理员可通过自然语言直接查询机构全貌、创建/编辑教师与学生、开设课程、编排/复制大纲树、批量排课与冲突检测等。
- **独立沙箱与多会话**：支持原生对话列表、自动生成标题、附件上传与流式输出（SSE）；助手工作目录安全隔离在 `data/dsh-home/workspace/`。
- **一键配置**：管理员在「系统设置」填入 DeepSeek API Key 即可测试连通性并启停助手，无需修改代码。

### 3. 实时课堂
- **上课周期与候课机制**：约定开课时间前 10 分钟起教师可点击「上课」进入 `in_progress` 状态，学生侧边栏「实时课堂」自动亮起呼吸红点提示并解锁入场发言与举手；切页、刷新或暂停录制均不会意外下课；点击「下课」自动结束并保存录制、标为已完课并打开点名。
- **举手后音视频连线**：支持学生举手排队申请连线，教师可选择接通「语音连线」「视频连线」或「暂不连线」；内置实时连线席卡片（摄像头画面与音频头像切换、软静音同步、教师快捷授权板书/挂断、学生自助挂断）。
- **屏幕共享与悬浮互动小窗**：教师共享屏幕时可开启系统级置顶互动小窗（优先 Document Picture-in-Picture，自动降级独立弹窗），风格与主页一致，实时同步屏幕共享/录制状态、举手队列、连线操作与学生聊天快捷回复。
- **多页互动白板**：支持画笔、橡皮擦、图形/公式文字/激光笔工具箱、撤销/重做、多页切换、黑板底纹、**本地离线 PDF.js 批量导入讲义为白板页**、按人授权学生板书、单页保存与全部导出长图。
- **流式分片录制与断点恢复**：上课中支持开始、暂停/继续、结束录制，按分片实时落盘；服务意外重启后可自动识别未归档会话并恢复导出回放，同时自动清理孤儿分片。

### 4. 录播与回放
- **直播回放管理**：课堂录制自动进入「待核看」，支持教师核看、发布、撤回、重命名与分段管理。
- **独立录播课程**：支持分章节上传预录视频、排序、发布/撤回、HTTP Range 拖动播放和视频书签。学生播放器使用与登录会话及具体视频绑定的短期凭证，观看时自动续期。服务端按在读或有效试听权限提供视频，学生画面带固定及移动的播放编号和时间。管理员可通过「账号列表」搜索播放编号核对账号。
- **学习进度统计**：记录学生上次播放位置与去重观看区间，自动计算完课比例，教师端可查看全班学习进度。

### 5. 课程管理与课程内容（多级大纲树）
- **课程列表**：按学科、授课形式（直播课 / 录播课 / 线下课）管理课程，支持**多教师联合授课**、可选**人数上限（含并发名额保护）**与一键钻取。
- **多级大纲树**：支持无限级目录、资料、录播视频、直播课次与图文说明混排；支持桌面端拖拽与触屏 `↑ / ↓` 调序、防环校验、大纲内直传文件/视频、批量导入未挂载资源及跨课程复制大纲结构。
- **课表排课**：支持列表与周历视图（周历支持点击单日快速建课）；支持固定间隔与**按星期多选**批量排课，提供**生成前冲突预览**与自动跳过冲突；自动校验教师、教室、学生时间冲突及时间轴线上并发峰值。

### 6. 课程作业（Markdown + KaTeX）
- **教师发布与批改**：支持 Markdown 与离线 **KaTeX 数学公式**渲染、作业附件上传；支持按课次/课程查看提交情况并在线评分、写评语与标记批改状态。
- **学生提交**：支持上传多张答题图片与文字说明、截止前重新提交，严格按在读课程隔离权限。

### 7. 课程群（实时答疑与通知）
- **实时消息推送**：基于 SSE 实时收发，支持未读角标、已读游标与 `@成员` 提醒。
- **富文本与多种消息**：支持讨论、提问（关联课次与题号、标记已解答）、群公告（置顶/取消置顶）、引用回复、本人撤回、图片粘贴/文件附件与课程资源卡片。
- **移动端适配**：手机端全屏贴底聊天布局，结合 `visualViewport` 动态适配输入法高度。

### 8. 班级、学生档案与系统设置
- **班级与学生**：支持一班多课、批量报名/退班/转班、意向跟进记录、限时试听授权与三遍刷题学习记录。
- **运维与数据管理**：机构名称与 Logo 定制、线上并发套餐配置、数据库下载与手动轮转校验、离线迁机备份与恢复、CSV 导出、存储空间统计与孤儿文件/过期会话清理。

## 快速开始（人类开发者 / 运维）

### 环境要求
- **Node.js >= 24**（使用内置 `node:sqlite` 与 `node:test`）
- **npm**（随 Node.js 附带，用于安装 `@deepseek-ai/dsh`）

### 安装与启动

```bash
# 1. 安装依赖
npm install

# 2. 启动服务（默认端口 3000）
npm start

# 或指定端口启动
PORT=8080 npm start
```

> **macOS 桌面快捷方式**：安装过一次依赖后，可直接双击根目录下的 [`启动教培工作台.command`](启动教培工作台.command)，脚本会自动检测端口、启动服务并在默认浏览器打开 `http://localhost:3000`。

首次访问页面时，系统会引导创建**初始管理员账号**，完成后即可登录使用。

### 运行自动化测试

```bash
npm test
```

## 公网部署指南（局域网外访问需要什么？）

如果仅在本机或教室局域网内使用，直接 `npm start` 即可。如果希望**校外学生、家长或居家教师通过公网随时访问**，除运行本程序外，还需要满足以下基础设施条件：

### 方案 A：云服务器正式部署（推荐）

1. **一台云服务器（VPS）**
   - 阿里云、腾讯云、华为云等「轻量应用服务器」即可，操作系统推荐 Ubuntu 22.04/24.04 或 Debian 12，安装 **Node.js >= 24**。
   - **配置参考（小班教培 10–30 人同时在线）**：`2 核 4GB 内存`、`50–100GB 云盘`（用于存放录播视频与课件）、`3–5Mbps 及以上公网带宽`（若同时观看录播的人较多，建议适当提高带宽或按流量计费）。
2. **域名 + HTTPS 证书（实时课堂必须）**
   - **关键原因**：现代浏览器安全策略规定，除 `http://localhost` 外，**麦克风、摄像头与屏幕共享功能必须在 `https://` 域名下才能调用**，直接用公网 IP 的 `http://` 访问将无法开麦或共享屏幕。
   - 推荐使用 **Caddy** 反向代理到本机 `127.0.0.1:3000`（自动申请并续期免费的 Let's Encrypt HTTPS 证书）：
     ```caddyfile
     class.yourdomain.com {
         reverse_proxy 127.0.0.1:3000 {
             flush_interval -1
         }
     }
     ```
   - 如使用 **Nginx**，需为 SSE 与大文件上传配置关闭缓冲与放开体积限制：
     ```nginx
     client_max_body_size 1024m;
     location / {
         proxy_pass http://127.0.0.1:3000;
         proxy_http_version 1.1;
         proxy_set_header Host $host;
         proxy_set_header X-Forwarded-Proto $scheme;
         proxy_set_header Connection "";
         proxy_buffering off;
         proxy_read_timeout 3600s;
     }
     ```
3. **TURN 中继服务器（跨网音视频连线强烈建议）**
   - 实时课堂采用浏览器端 WebRTC 传输音视频。局域网内通常可 P2P 直连，但在公网环境下，部分学生/教师位于校园网、企业防火墙或对称 NAT 后，仅靠免费 STUN 可能出现「能看到白板聊天，但听不到声音/看不到视频」的情况。
   - 解决方式：在同一台云服务器上部署开源的 **coturn**（开放 UDP/TCP `3478` 端口及中继端口段），或在云厂商购买 TURN 服务，然后以管理员身份登录工作台，在 **「系统设置 → WebRTC ICE/STUN/TURN 服务器」** 中填入对应地址与凭据即可。
4. **进程守护与定时备份**
   - 使用 `pm2` 或 `systemd` 托管 `node src/server.js`，防止终端退出导致服务停止；定期将 `data/` 目录同步到云盘或对象存储。

### 方案 B：本地电脑 + 内网穿透（临时试用 / 零服务器成本）

- 若暂时不想购买云服务器，可在运行本系统的电脑上搭配 **Cloudflare Tunnel**（免费，自动提供 `https://` 域名）、`frp` 等内网穿透工具对外提供 HTTPS 访问。
- **局限**：宿主电脑需保持开机不休眠，家用宽带上行速度有限，且无独立 TURN 时跨运营商音视频连线稳定性不如方案 A。

> **关于大班直播的补充建议**：内置实时课堂基于 P2P Mesh 架构，最适合 **1 对 1 及 10 人以内的小班互动与答疑**；若单节直播课超过 15–30 人，建议在排课时填写「外接课堂链接」（如腾讯会议、ClassIn、Zoom），本系统继续统一承载课程大纲、白板资料、录播回放、作业批改与课程群答疑。

## AI 自动部署指南（For AI Agents）

如果你是接管本项目的 AI Agent，请严格按以下步骤执行检查、部署与验证：

### 1. 环境预检
- **检查 Node.js 版本**：执行 `node -v`，确认主版本号 `>= 24`。
  - *注意（macOS）*：若默认 shell 提示 `node: command not found`，先注入 Homebrew 路径：`export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH"`。
- **检查端口占用**：确认目标端口（默认 `3000`，可通过 `PORT` 环境变量覆盖）未被占用（如 `lsof -iTCP:3000 -sTCP:LISTEN`）。

### 2. 安装与测试验证
```bash
npm install
npm test
```
- **预期结果**：`npm test` 应全部通过（当前为 20/20 passed，0 failed）。若测试失败，请先排查环境或权限问题再启动服务。

### 3. 启动服务
- **前台 / 开发验证**：
  ```bash
  PORT=3000 node src/server.js
  ```
- **后台 / 生产守护（推荐）**：使用 `pm2`、`systemd` 或 `nohup` 托管 `node src/server.js`，并确保工作目录为项目根目录。

### 4. 就绪探测与初始化（Verification & Bootstrap）
- **健康/就绪检查**：请求 `GET http://127.0.0.1:<PORT>/api/state`。
  - 返回 HTTP `200` 且包含 JSON 即表示服务已就绪。
  - 若返回中 `needsSetup` 为 `true`，说明系统尚未创建初始管理员。
- **初始化管理员**：
  - 优先提示用户打开浏览器完成引导；若需无头脚本初始化，可调用：
    ```bash
    curl -sS -X POST http://127.0.0.1:3000/api/setup \
      -H "Content-Type: application/json" \
      -d '{"name":"教务管理员","username":"13800138000","password":"your-strong-password","subject":"综合"}'
    ```

### 5. 生产反向代理与持久化关键约束（必读）
1. **持久化目录**：部署时挂载整个 `WORKBENCH_DATA_DIR`（默认 `data/`）。用 `npm run --silent data -- path` 查看当前版本的位置。当前版本内有以下文件：
   - `workbench.db`、`workbench.db-wal`、`workbench.db-shm`（SQLite WAL 数据库文件，须一并保留）
   - `uploads/`（课件、板书、作业图片、录制分片、回放与录播视频）
   - `backups/`（本地轮转数据库备份）
   - `dsh-home/`（DeepSeek 智能助手的凭据、会话、工作区与附件）
2. **反向代理（Nginx / Caddy）配置要点**：
   - **关闭缓冲以支持 SSE**：针对 `/api/qa/stream`、`/api/classroom/`、`/api/assistant/stream` 路由关闭代理缓冲（Nginx 需设置 `proxy_buffering off; proxy_read_timeout 3600s;`）。
   - **放开上传体积限制**：课程录播与高清课件上传可能较大，Nginx 建议设置 `client_max_body_size 1024m;`。
   - **透传协议头**：转发 `X-Forwarded-Proto $scheme`（及 WebSocket/SSE 所需头部），确保在 HTTPS 域名下 `wb_session` Cookie 自动启用 `Secure` 属性。
3. **DeepSeek 智能助手网络要求**：
   - 使用内置 AI 助手时，服务器需能出网访问 `https://api.deepseek.com`。API Key 由管理员登录后在前端「系统设置」配置，无需通过环境变量注入。

## 恢复初始状态

停止服务后，在项目根目录运行 `npm run data -- reset`，再运行 `npm start`。工作台会在数据根目录的 `instances/` 下启用一个空白版本，下次打开显示管理员初始化页面。原版本可以用命令输出的 `npm run data -- restore <版本名称>` 切回，切换后需重启服务。第一次重置前的数据版本叫 `original`。

`npm run --silent data -- path` 显示当前版本的目录。项目默认的整个 `data/` 都已加入 Git 忽略规则。浏览器里的主题、播放倍速和导航记录按数据版本使用，登录 Cookie 需要通过对应版本的数据库验证。

## 备份与迁机恢复

「系统设置 → 数据与存储」下载的是 SQLite 数据库。迁机需要同时保存数据库和 `uploads/` 里的课件、作业图片、回放及录制分片。请在无课、无上传时停止服务，再从项目根目录执行备份。备用目录的上级需已存在，备份和恢复目标应使用新目录。

```bash
node src/backup.js backup "$(npm run --silent data -- path)" /path/to/backups/workbench-2026-11-25
node src/backup.js restore /path/to/backups/workbench-2026-11-25 /path/to/workbench-restored
WORKBENCH_HOST=127.0.0.1 PORT=3100 WORKBENCH_DATA_DIR=/path/to/workbench-restored npm start
```

备份与恢复都会运行 SQLite 完整性检查并核对数据库引用的上传文件。命令退出成功后，可用原来的学生账号登录本机演练实例，打开课件、作业图片和回放。备份目录含账号及课程数据，请按原数据的访问权限保存。助手运行目录 `dsh-home/` 需单独迁移时，停止服务后按实际需要单独保存。
